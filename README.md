# 🌐 欢迎参与翻译！
我们欢迎任何语言的翻译贡献！

 👥 如何参与贡献？
由于原仓库已存档，所有贡献请在本仓库（社区版）进行：

1. Fork 本仓库 到你的账号。
2. 创建你的功能分支 (`git checkout -b feature/AmazingFix`)。
3. 提交你的修改 (`git commit -m 'Add some AmazingFix'`)。
4. 推送到分支 (`git push origin feature/AmazingFix`)。
5. 在本仓库提交 Pull Request。

我们会尽快审核并合并！
